# RankedMoments Privacy Policy

**Last updated: August 13, 2026**

## Overview

RankedMoments is a local desktop application designed to help users discover candidate videos and create editable short-form ranking video projects.

RankedMoments uses the YouTube Data API to search for publicly available YouTube videos and display relevant search results for manual review.

The application is currently operated as an independent developer project and is primarily intended for local use.

## YouTube API Services

RankedMoments uses YouTube API Services.

By using features of RankedMoments that interact with YouTube, users should also review:

- YouTube Terms of Service
- Google Privacy Policy

The official links for these policies are provided below this document when publishing.

## Information RankedMoments Accesses

Through the YouTube Data API, RankedMoments may access publicly available YouTube information such as:

- Video IDs
- Video titles
- Video descriptions
- Thumbnail information
- Channel names and identifiers
- Publication information
- Search-result metadata
- Public video URLs

RankedMoments currently uses an API key for public YouTube search.

RankedMoments does **not currently request access to a user's private YouTube account information through Google OAuth**, and it does not request or store users' YouTube usernames or passwords.

## How Information Is Used

YouTube API data is used to:

- Search for videos that match a user's request
- Display candidate videos for manual review
- Rank and organize search results
- Avoid unnecessarily showing duplicate results
- Remember previously encountered videos when the user chooses to use that feature
- Help users organize selected material into local RankedMoments projects

YouTube API data is not used to create advertising profiles.

## Local Storage

RankedMoments is primarily a local desktop application.

Search information, candidate metadata, Clip Scout session information, seen-video history, prepared-clip information, and project information may be stored locally on the user's computer so that sessions and projects can persist between application restarts.

RankedMoments does not currently operate a remote user-account database for storing this information.

## Local Video Media

RankedMoments does not use the YouTube Data API to download YouTube videos.

When RankedMoments analyzes or edits video media, the source media is provided separately by the user.

Prepared clips and ranking-project media are stored locally on the user's computer.

Local video analysis may be performed using locally installed AI software and local media-processing tools.

## Sharing of Information

RankedMoments does not sell personal information or YouTube API data.

RankedMoments does not currently sell advertising or share user information with advertisers.

Information obtained through YouTube API Services may be transmitted to Google/YouTube as required to perform YouTube API requests and display YouTube functionality.

RankedMoments does not intentionally provide locally stored Clip Scout sessions, prepared media, or ranking projects to third parties.

## Google and YouTube

YouTube and Google may independently process information when users interact with YouTube services, YouTube API functionality, or embedded YouTube content.

Google's handling of information is governed by the Google Privacy Policy.

RankedMoments does not control Google's or YouTube's independent data-processing practices.

## Cookies and Similar Technologies

RankedMoments itself is a local desktop application and does not currently use advertising cookies or third-party analytics cookies.

YouTube or Google components used by the application may use cookies or similar technologies according to Google's own policies.

## Data Retention and Deletion

Locally stored RankedMoments information is retained to provide application functionality such as:

- Session persistence
- Search history
- Seen-video tracking
- Candidate management
- Prepared clips
- Ranking projects

Users can reset their Clip Scout seen-video history and start new Scout sessions using controls provided by RankedMoments.

Local application data and projects can also be removed from the user's computer.

RankedMoments does not intentionally retain user information longer than necessary for the application's functionality.

## Security

RankedMoments is designed to keep application data and media local where practical.

API credentials are intended to remain private and are not intentionally exposed through the user interface or included in public project files.

Reasonable measures are used to protect locally stored application data and API credentials from unauthorized access.

## Changes to This Privacy Policy

This Privacy Policy may be updated if RankedMoments adds or changes features, data sources, external services, authentication methods, or data-processing practices.

The date at the top of this document will be updated when material changes are made.

## Contact

For questions about this Privacy Policy or RankedMoments' privacy practices, contact the developer using the contact information associated with the RankedMoments project or its public GitHub repository.
